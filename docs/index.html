Gmail MCP Server

An open-source Model Context Protocol server that connects one or more Gmail accounts to an AI assistant such as Claude. It runs entirely on your own computer.

  • Search, read, draft, reply, forward and send email from any linked account.
  • Every send requires an explicit confirmation step.
  • Your Google OAuth tokens are stored in your operating system's keychain and never leave your machine.

Source code and setup instructions: github.com/Shravanth007/Gmail-MCP
