Privacy Policy

Last updated: 6 November 2026

Gmail MCP Server is open-source software that you install and run on your own computer. There is no hosted service, no central server, and no account with us.

What data is accessed

With your permission, the software uses the Gmail API with the gmail.readonly and gmail.compose scopes to read messages, create drafts and send email from the Google accounts you choose to link.

Where data is stored

  • OAuth tokens are stored in your operating system's credential store (Windows Credential Manager, macOS Keychain or Linux Secret Service) on your computer.
  • A local file lists the email addresses you linked and any labels you gave them. It contains no credentials.
  • Email content is fetched on demand and passed to the AI assistant you connected. It is not stored by this software and is never sent to the authors of this software.

What we collect

Nothing. The authors of this software do not receive, collect, log or sell any of your data. No analytics or telemetry are included.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Run gmail-mcp remove-account to revoke and delete a token, or remove the app at myaccount.google.com/permissions.

Contact
